# Создание личного репозитория
Открыть терминал, перейти или создать каталог, где будт расположен репозиторий, и выполнить команду:
```
git init
```
Создать файл .gitignore и добавить в него необходимые правила, например
```
touch .gitignore
echo "*.log" >> .gitignore
```
